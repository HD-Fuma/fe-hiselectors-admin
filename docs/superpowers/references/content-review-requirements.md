# 콘텐츠 검수 요구사항

## 검수 파이프라인

1. 수집
   - 이미지·영상
   - 제목, 본문, 해시태그, 멘션, URL
2. 자동 추출
   - 이미지·영상 속 글자 추출(OCR)
   - 영상 음성의 텍스트 변환(ASR/STT)
   - 등장 시간과 화면 위치 저장
3. 규칙 검사
   - 광고·협찬 표시 문구
   - 필수 문구, 해시태그, 멘션
   - 금지 문구
   - URL과 연결 주소
4. AI 분석
   - 제품 설명과 제출 정보의 일치 여부
   - 과장되거나 오해할 표현 여부
   - 브랜드 분위기 적합성
   - 수정할 부분과 근거 위치
5. 최종 처리
   - 관리자 승인·반려
   - 수정본과 이전 버전 비교

## 화면 최소 표시값

- 제출일
- 리포트 생성일
- 검수 이력
- OCR로 추출된 화면 글자
- STT로 추출된 음성 문장과 맥락 요약
- 욕설·폭력성·음란물 여부
- OCR을 포함한 광고 표시 상태
- 위반 내역과 수정 필요 내용
- 이전 버전과 수정본의 차이
- 승인·반려 버튼

## UI 원칙

- 위반 항목은 근거가 되는 영상 시간 또는 화면 위치와 연결한다.
- 자동 추출 결과, 규칙 검사 결과, AI 판단을 구분해 표시한다.
- 승인·반려 전에 원문과 수정본의 차이를 확인할 수 있어야 한다.
- AI 판단만으로 최종 상태를 확정하지 않고 관리자의 최종 처리를 유지한다.
