# 정산 집계 예정 상태 라벨 변경

## 목표

정산 지급 상태 코드 `CALCULATING`의 사용자 표시 문구를 `집계 예정`으로 통일한다.

## 구조와 데이터 흐름

- 정산 상태 코드와 표시 문구의 기준은 `src/entities/settlement/model.ts`가 담당한다.
- `SETTLEMENT_STATUSES`와 `SETTLEMENT_STATUS_FILTERS`의 `CALCULATING` 라벨을 함께 변경한다.
- 상태 코드, 색상 톤, API 요청 값은 현재 계약을 유지한다.

## 적용 화면

공통 매핑을 사용하는 지급 상태 필터, 지급 상태 현황, 정산 지급 목록, 정산 상세, 셀렉터스 상세의 정산 이력에 `집계 예정`을 표시한다. 작업 실행 이력의 `정산 계산`, `예상 정산 계산 중`, `정산 재계산 중`은 배치 작업 상태 문구로 유지한다.

## 오류 처리

API와 상태 코드는 현재 계약을 유지하므로 추가 오류 흐름은 생기지 않는다. 알 수 없는 상태 코드는 기존 fallback 문구를 사용한다.

## 검증

- 공통 상태 라벨 테스트에서 `CALCULATING`이 `집계 예정`으로 변환되는지 확인한다.
- 정산 화면 테스트의 필터, 목록, 상세 문구를 `집계 예정` 기준으로 갱신한다.
- 관련 테스트와 정적 검사를 실행한다.
