# FUMA 관리자 사이드바 브랜드·계정 정보 디자인

## 결정

- 사이드바 상단은 의미 없는 `FUMA ADMIN CONSOLE` 대신 `Selectors`를 주 브랜드로 표시한다.
- 청록색 셀렉터스 마크와 `SELECTORS` 워드마크, `CREATOR OPERATIONS` 보조 문구를 사용한다.
- 사이드바 하단에는 현재 로그인한 `관리자`와 역할 `FUMA 운영자`를 표시한다.
- 같은 계정 정보가 중복되지 않도록 상단 바에서는 이름·역할을 제거하고 설정·로그아웃 유틸리티만 남긴다.

## 구조

```
┌ Selectors brand ┐
│ accordion menus │
│                 │
├ 관리자          │
│ FUMA 운영자  로그아웃 │
└─────────────────┘
```

브랜드 영역, 메뉴 스크롤 영역, 계정 영역의 세 행으로 사이드바를 구성한다. 메뉴만 스크롤하고 브랜드와 계정 정보는 고정한다.

## 접근성

- 로그아웃은 텍스트와 아이콘을 함께 사용한 명시적 버튼으로 제공한다.
- 계정 정보는 장식이 아닌 읽을 수 있는 텍스트로 남긴다.
- 기존 메뉴 아코디언과 정확한 라우트 활성 표시는 변경하지 않는다.
