# 크리에이터 풀 프로필·콘텐츠 카드 개편 설계

## 1. 배경과 결정

크리에이터 풀의 기본 단위는 게시물이 아니라 크리에이터다. 목록에서 사람의 정체성과 콘텐츠 스타일을 동시에 비교할 수 있도록, 기존 고밀도 표를 **프로필 중심 콘텐츠 증거 카드**로 개편한다. 사용자가 선택한 A안을 기본 화면으로 사용하고, 기존 표는 보조 목록 보기로 유지한다.

이 작업은 정적 프론트엔드 프로토타입 범위다. 외부 API 호출이나 업무 데이터 변경은 추가하지 않는다.

## 2. 화면 구조

기존 `PageHeader`, 검색 패널, 페이지네이션과 관리자 셸은 유지한다.

검색 패널 아래 결과 영역은 다음 순서로 구성한다.

1. 결과 건수, 정적 정렬 문구 `AI 적합도순`, `카드 보기 / 목록 보기` 전환
2. 기본값인 3열 크리에이터 카드 그리드
3. 목록 보기 선택 시 기존 `DenseTable`
4. 페이지네이션

검색 결과가 없으면 카드와 표 대신 기존 문체의 `검색 결과가 없습니다.` 상태를 표시한다.

## 3. 크리에이터 카드

각 카드는 다음 다섯 구역을 가진다.

1. **콘텐츠 모자이크**: 인기 콘텐츠 3개를 대표 1개와 보조 2개로 배치한다. 각 콘텐츠에는 출처 플랫폼 아이콘과 영상 여부를 표시한다.
2. **프로필 정체성**: 원형 프로필 이미지, 이름, 대표 핸들, 카테고리, 연결된 플랫폼 아이콘을 항상 노출한다.
3. **비교 지표**: 팔로워·구독자, 평균 조회, 평균 반응률을 같은 순서로 표시한다.
4. **운영 상태**: AI 적합도 또는 생성 대기, 티어, 제안 상태, 최근 활동일을 표시한다.
5. **다음 행동**: `상세 보기`와 제안 상태에 맞는 `영입 제안 / 제안 이력 / 다시 제안` 링크를 제공한다.

`상세 보기`는 `/creators/:creatorId`로 이동한다. 제안 액션은 아래처럼 결정한다.

- `미제안`: `영입 제안` → `/creators/:creatorId#proposal`
- `발송 실패`: `다시 제안` → `/creators/:creatorId#proposal`
- `발송 대기`, `발송 완료`, `셀렉터스 전환`: `제안 이력` → `/proposals?creator=:creatorId`

카드는 hover에 핵심 정보를 숨기지 않는다. hover는 낮은 그림자와 1–2px 이동만 사용하고, `prefers-reduced-motion`에서는 전환을 제거한다.

## 4. 플랫폼 아이콘

지원 플랫폼 타입은 `Instagram`, `YouTube`, `Facebook`으로 제한한다.

- Instagram: 카메라 글리프와 보라·주황 그라디언트
- YouTube: 빨간 라운드 사각형과 흰색 재생 삼각형
- Facebook: 파란 원과 흰색 `f`

아이콘은 장식으로만 처리하지 않고 `Instagram`, `YouTube`, `Facebook` 접근성 이름을 제공한다. 작은 원형 아이콘만 사용하지 않고, 콘텐츠 모자이크의 대표 출처에서는 아이콘과 플랫폼 이름을 함께 표시한다.

## 5. 시각 방향

기존 HSAS 관리자 UI의 평평한 흰색 표면, 얇은 회색 경계, 청록색 주요 액션과 `Malgun Gothic`을 유지한다. 이번 화면의 시각적 서명은 **크리에이터마다 다른 오프라인 SVG 콘텐츠 모자이크와 프로필 초상**이다.

외부 이미지 URL은 사용하지 않는다. 콘텐츠 미리보기와 프로필은 컴포넌트에서 렌더하는 결정적 SVG 아트워크를 사용해 visual test에서 외부 네트워크 요청이 발생하지 않도록 한다. 카드 외부의 장식은 추가하지 않아 이미지 영역만 시각적 초점이 되게 한다.

주요 색상은 기존 청록 `#168F78`, 진회색 `#24282B`, 흰색 `#FFFFFF`, 경계 `#D8DCDD`에 플랫폼 색상 YouTube `#FF0033`, Facebook `#1877F2`, Instagram 그라디언트를 더한다.

## 6. 컴포넌트와 데이터 경계

- `CreatorListPage`: 검색 조건, 보기 모드 상태, 결과/빈 상태 조합
- `CreatorResultToolbar`: 건수, 정적 정렬 문구, 보기 모드 전환
- `CreatorCardGrid`: 크리에이터 배열을 카드로 렌더
- `CreatorEvidenceCard`: 카드의 정보 우선순위와 액션 조합
- `CreatorMediaMosaic`: 세 개의 콘텐츠 미리보기
- `PlatformIcon`: 세 플랫폼의 일관된 브랜드 표시와 접근성 이름
- `CreatorArtwork`: 네트워크 없는 프로필·콘텐츠 SVG 표현

fixture에는 `Platform` 유니온, 대표 콘텐츠 3개, 아트워크 변형 키를 추가한다. 평균 조회는 채널별 평균 조회의 산술 평균, 평균 반응률은 전체 평균 반응 수를 전체 평균 조회 수로 나눈 값으로 화면에서 계산한다.

- 평균 조회는 채널이 없으면 `0`, 그 외에는 `Math.round(조회 수 합계 / 채널 수)`로 계산한다.
- 평균 반응률은 `반응 수 합계 / 조회 수 합계 × 100`이며 조회 수 합계가 `0`이면 `0.0%`로 표시한다.
- 팔로워와 평균 조회는 `Intl.NumberFormat("ko-KR", { notation: "compact", maximumFractionDigits: 1 })`, 반응률은 소수점 한 자리와 `%`로 표시한다.
- `cr-003 이지아` fixture는 Instagram과 Facebook 채널을 가지며, 인기 콘텐츠 세 개 중 하나의 출처를 Facebook으로 둔다. 따라서 기본 카드 화면에서 Facebook 아이콘을 반드시 확인할 수 있다.
- 대표 핸들은 fixture의 `channels[0].handle`을 사용하고 채널이 없으면 `채널 정보 없음`으로 표시한다.
- `AI 적합도순`은 fixture 프로토타입의 현재 배열 순서를 설명하는 비대화형 문구다. 실제 정렬 상태나 API 요청은 이번 범위에 포함하지 않는다.

## 7. 접근성 및 오류 처리

- 카드 그리드는 이름 있는 `list`, 카드는 `listitem`으로 제공한다.
- 연결 플랫폼 아이콘은 각각 `Instagram 플랫폼`, `YouTube 플랫폼`, `Facebook 플랫폼` 이름을 가진다. 콘텐츠 출처 배지 안의 중복 아이콘은 장식으로 숨기고 플랫폼 텍스트만 읽히게 한다.
- 프로필 SVG는 `{크리에이터명} 프로필 이미지`, 콘텐츠 SVG는 `{크리에이터명} 인기 콘텐츠: {콘텐츠 제목}` 이름을 가진다.
- 반복 액션은 `{크리에이터명} 상세 보기`, `{크리에이터명} 영입 제안`, `{크리에이터명} 제안 이력`, `{크리에이터명} 다시 제안`처럼 카드별 접근성 이름을 가진다.
- 보기 전환은 실제 `button`과 `aria-pressed`를 사용한다.
- 키보드 포커스는 기존 전역 청록 outline을 유지한다.
- 콘텐츠 배열이 비어 있거나 3개보다 적어도 컴포넌트가 오류를 내지 않고 있는 항목만 표시한다.
- 알 수 없는 플랫폼 값은 TypeScript 유니온에서 컴파일 단계에 차단한다.

## 8. 테스트와 완료 조건

1. `/creators`가 기본 카드 보기로 열리고 네 명의 크리에이터 카드가 렌더된다.
2. Instagram, YouTube, Facebook 선택 옵션이 있고, 이지아 카드에 Instagram·Facebook 아이콘과 Facebook 출처 콘텐츠가 표시된다.
3. 각 카드에 프로필, 콘텐츠 3개, 세 지표, 운영 상태, 두 액션이 노출된다.
4. 결과 도구 모음에 `AI 적합도순`이 표시되고, 목록 보기 버튼을 누르면 기존 표와 열 구조가 렌더된다.
5. `fixture=empty`는 카드와 표 없이 빈 상태를 표시한다.
6. 단위 테스트, ESLint, TypeScript 프로덕션 빌드가 성공한다.
7. 1440×900 브라우저 검증에서 카드 3열, 텍스트 잘림, 콘솔 오류, 외부 네트워크 요청이 없어야 한다.
