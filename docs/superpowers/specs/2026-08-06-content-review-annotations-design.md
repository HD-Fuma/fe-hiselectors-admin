# 콘텐츠 검수 위반 위치 주석 UI

## 목적

검수자가 우측 분석 결과를 읽고 원본 콘텐츠에서 문제 위치를 다시 찾지 않도록, 위반 근거를 콘텐츠 원본 위에 직접 표시하고 같은 높이의 안내문과 연결한다.

## 표시 원칙

- 이미지 위반은 문제 좌표에 번호 핀과 얕은 반투명 영역을 표시한다.
- 본문 위반은 문제가 된 문구만 밑줄과 옅은 적색 배경으로 강조한다.
- URL 위반은 해당 링크 행 전체를 강조한다.
- 각 표시 옆에는 번호가 같은 안내문을 배치한다. 안내문에는 위반 유형, 근거 위치, 수정 지침만 둔다.
- 자동 분석 출처는 작은 `자동 감지` 표식으로만 노출한다.
- 문제없는 신규 콘텐츠와 해결된 현재 수정본에는 표시하지 않는다. 위반 수정본의 직전 판정본에만 과거 위반 위치를 표시한다.

## 레이아웃

콘텐츠 미리보기 한 개는 `원본 + 220px 안내 레일`의 두 열로 구성한다. 프로필은 전체 폭, 미디어·본문·URL은 각각 독립된 grid row가 되고 해당 안내문은 같은 row의 두 번째 열에 놓인다. 따라서 안내문은 대상 섹션과 같은 높이에 유지되며, 번호가 같은 마킹과 안내문 사이에는 짧은 수평 연결선을 둔다. 한 섹션에 안내문이 여러 개면 마킹의 원본 순서대로 수직 정렬하고 8px 간격을 유지해 겹침을 막는다.

이전·현재 비교 화면에서 어느 한쪽에 주석이 있으면 두 버전을 세로로 쌓아 원본 폭을 확보한다. 주석이 없는 일반 수정 비교는 기존 좌우 배치를 유지하고, 해결된 현재 수정본에는 안내 레일을 렌더링하지 않는다.

```text
┌──────────────────────── SNS 원본 ────────────────────────┐  ┌─ 위반 안내 ─────┐
│ 이미지                  ①                                │──│ ① 과장 표현     │
│                                                          │  │ 이미지 1 중앙   │
│ 본문: 지금 가장 저렴하게 구매하세요. ②                  │──│ ② 문구 수정     │
│ URL: short.example/golf                      ③           │──│ ③ 공식 URL 사용 │
└──────────────────────────────────────────────────────────┘  └─────────────────┘
```

## 데이터 계약

`ContentSnapshot`에 선택적 `annotations` 배열을 추가한다.

```ts
type ContentAnnotationTarget =
  | {
      kind: "media";
      mediaIndex: number;
      box: { x: number; y: number; width: number; height: number };
    }
  | {
      kind: "text";
      quote: string;
      occurrence: number;
    }
  | {
      kind: "url";
      targetIndex: number;
    };

interface ContentAnnotation {
  id: string;
  target: ContentAnnotationTarget;
  title: string;
  reason: string;
  location: string;
  guidance: string;
  source: "자동 감지" | "운영자";
  severity: "warning" | "critical";
  state: "active" | "resolved";
}
```

미디어 영역 좌표는 백분율로 저장하고, 본문은 `quote + occurrence`, URL은 `targetIndex`로 대상과 연결한다. 각 target variant의 필드는 필수다. UI는 `state: "active"`인 주석만 필터링한 뒤 마킹, 안내 레일, 세로 비교 레이아웃을 결정한다. fixture에서는 `ct-002`의 직전 위반 판정본에 이미지 OCR, 과장 문구, 단축 URL 주석을 넣는다. `detectedIssues`나 분석 문장에서 위치를 추론하지 않는다.

## 컴포넌트

- `AnnotatedMediaTiles`: 기존 미디어 타일 내부에 좌표 기반 영역과 핀을 표시한다.
- `AnnotatedText`: 원문 문자열에서 첫 번째 정확한 `quote`를 찾아 강조한다.
- `AnnotationRail`: 미디어·본문·URL row별로 같은 snapshot의 활성 주석을 원본 위치 순서대로 표시한다.
- `SnapshotPanel`: 주석 유무에 따라 일반 SNS 미리보기 또는 `원본 + 안내 레일` 구조를 선택한다.

## 예외 처리와 접근성

- 인용 문구나 인덱스가 원본과 맞지 않으면 원본 강조는 생략하되 안내문은 해당 섹션 row에 유지한다.
- 이미지 `object-fit: cover`에 맞춰 백엔드도 표시 영역 기준의 정규화 좌표를 제공하는 계약으로 둔다.
- 번호 핀과 안내문은 같은 `aria-label`을 사용하고, 색상 외에도 번호·아이콘·텍스트로 위반을 구분한다.
- 모바일·좁은 화면에서는 안내문을 원본 바로 아래에 배치한다.
- 링크의 기본 동작과 기존 검수 액션은 변경하지 않는다.

## 확인 범위

- 위반 판정본의 이미지·본문·URL 세 위치에 정확한 마킹이 표시된다.
- 번호가 같은 안내문이 콘텐츠 바로 옆에 표시된다.
- 신규 콘텐츠와 해결된 현재 수정본에는 마킹이 없다.
- 해결 상태 주석만 있는 snapshot은 안내 레일과 세로 비교 모드를 만들지 않는다.
- 기존 상세 화면과 미디어 렌더링 테스트가 유지된다.
- 1600px 관리자 화면과 좁은 화면에서 겹침이 없다.
