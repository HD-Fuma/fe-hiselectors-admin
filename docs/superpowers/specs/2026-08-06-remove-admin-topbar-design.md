# 관리자 상단 바 제거 설계

## 목표

관리자 화면 위쪽의 `더현대Hi 셀렉터스 운영` 문구와 해당 문구만 담고 있는 44px 높이의 상단 바를 함께 제거한다. 작업 탭이 사이드바 오른쪽 작업 영역의 최상단에 바로 배치되어 불필요한 빈 공간이 남지 않아야 한다.

## 검토한 방식

1. **상단 바 전체 제거(채택)**: 문구와 빈 영역을 모두 없애며 사용자가 요청한 간결한 화면을 만든다.
2. 문구만 제거: 기존 상단 바의 44px 빈 영역이 남아 공간 낭비가 계속된다.
3. 상단 바를 다른 정보로 대체: 현재 요청 범위를 벗어나고 새로운 정보 구조가 필요하다.

## 변경 설계

- `AppShell`에서 `AdminTopbar` 렌더링과 import를 제거한다.
- 더 이상 사용되지 않는 `AdminTopbar` 컴포넌트와 전용 CSS 규칙을 삭제한다.
- 사이드바, 작업 탭, 본문 콘텐츠의 구조와 동작은 그대로 유지한다.
- 화면별 데이터 흐름과 라우팅에는 변화가 없다.
- 제거 대상은 관리자 셸에 한정하며 로그인 화면과 메시지 작성 화면에 있는 다른 `더현대Hi` 문구는 유지한다.

## 오류 및 경계 조건

상단 바는 상태나 이벤트를 소유하지 않으므로 별도 오류 처리는 필요하지 않다. 모든 관리자 라우트가 같은 `AppShell`을 사용하므로 한 번의 셸 변경으로 전체 관리자 화면에 동일하게 적용한다.

## 검증

- 셸 테스트에서 상단 바가 렌더링되지 않고 요청 문구가 사라졌는지 확인한다.
- 기존 작업 탭, 사이드바 관리자 컨트롤, 라우팅 관련 테스트가 계속 통과하는지 확인한다.
- 프로덕션 빌드를 실행해 미사용 import나 CSS 제거로 인한 컴파일 오류가 없는지 확인한다.
