# 한국 여성 크리에이터 미디어 교체 설계

## 목표

크리에이터 풀의 해외 스톡 사진을 성인 한국 여성 인플루언서 중심의 실사형 이미지로 교체한다. 각 크리에이터는 프로필 사진과 대표 게시물에서 같은 인물로 인식되어야 하며, 현재 가상 이름·카테고리·콘텐츠 제목과 자연스럽게 어울려야 한다.

## 검토한 방식

1. **가상의 실사형 한국 여성 인플루언서 이미지 생성(채택)**: 초상권과 실제 인물 오인 위험 없이 인물·카테고리 일관성을 확보할 수 있다.
2. 실존 유명 인플루언서 사진 사용: 초상권, 출처, 브랜드 제휴 오인 위험이 있어 사용하지 않는다.
3. 한국 여성 스톡 사진 조합: 빠르지만 한 크리에이터의 프로필과 게시물을 같은 인물로 맞추기 어렵고 현재 더미 사진의 불일치 문제가 반복된다.

## 이미지 구성

네 크리에이터 모두 서로 다른 성인 한국 여성으로 표현한다. 특정 실존 인물을 닮게 만들지 않으며 이미지 안에 로고, 워터마크, 읽을 수 있는 문구를 넣지 않는다.

| 크리에이터 | 이미지 톤 | 게시물 구성 |
| --- | --- | --- |
| 김서연 (`cr-001`) | 세련된 서울 뷰티·패션 인플루언서, 깨끗한 자연광과 소프트 핑크 포인트 | 데일리룩, 톤 메이크업, 출근 룩북 |
| 박도윤 (`cr-002`) | 따뜻하고 친근한 리빙·푸드 크리에이터, 아늑한 주방과 홈카페 무드 | 집밥 조리, 홈카페, 주말 한 상 |
| 이지아 (`cr-003`) | 밝고 활동적인 여행·라이프스타일 인플루언서, 자연광과 산뜻한 여행 색감 | 바다 산책, 도시 여행, 여행 패킹 |
| 오하늘 (`cr-004`) | 감각적인 푸드·카페 인플루언서, 고급스러운 브런치와 디저트 무드 | 과일 디저트, 브런치, 카페 신메뉴 |

각 인물은 1장의 정면 프로필과 3장의 정사각형 게시물 사진을 갖는다. 게시물 사진 중 최소 2장에는 동일 인물의 얼굴이나 상반신이 자연스럽게 나타나고, 나머지 1장은 해당 인물의 손·스타일링·음식·여행 소품처럼 계정 맥락을 잇는 장면으로 구성한다.

## 에셋과 데이터 연결

- 생성 이미지는 640×640 JPEG로 저장한다.
- 기존 지원자 화면이 재사용하는 스톡 파일은 덮어쓰지 않는다.
- 새 파일은 `public/creator-media/kr-cr-<번호>-profile.jpg`와 `kr-cr-<번호>-01.jpg`부터 `-03.jpg`까지 총 16개로 추가한다.
- `src/features/creators/fixtures.ts`의 네 크리에이터 이미지 경로만 새 파일로 변경한다.
- 크리에이터 풀, 크리에이터 상세, 제안 작성 화면은 같은 크리에이터 fixture를 사용하므로 새 이미지가 함께 적용된다.
- 지원자 분석 화면은 기존 경로를 유지해 요청 범위 밖의 시각 변경을 방지한다.
- AI 생성 에셋이라는 출처와 제작 목적을 `docs/superpowers/references/creator-media-sources.md`에 기록한다.

## 렌더링과 오류 처리

현재 `CreatorProfilePhoto`와 `CreatorContentPhoto`의 로딩 및 대체 이미지 동작을 그대로 사용한다. 파일 누락이나 로딩 실패 시 기존 이름·콘텐츠 제목 기반 대체 UI가 표시되므로 별도 컴포넌트 변경은 하지 않는다.

## 검증

- 16개 파일이 모두 존재하고 640×640 JPEG인지 확인한다.
- fixture와 카드 테스트의 예상 경로를 새 파일명으로 갱신하고, 프로필 1장과 게시물 3장이 각 크리에이터에 연결되는지 확인한다.
- 크리에이터 관련 단위 테스트와 프로덕션 빌드를 실행한다.
- 브라우저에서 크리에이터 풀의 네 카드와 상세 화면을 확인해 이미지 로딩 실패, 얼굴 잘림, 카드 오버플로가 없는지 검증한다.
- 생성 결과가 특정 실존 인물처럼 보이거나, 미성년자로 보이거나, 손·얼굴이 심하게 왜곡되거나, 이미지 안에 읽을 수 있는 문구·브랜드 로고가 있으면 해당 이미지를 다시 생성한다.
