# FUMA 관리자 사이드바 색상 복원 및 아코디언 메뉴 디자인

## 목표

관리자 단일 사이드바의 구조는 유지하면서, 색상을 기존 현대백화점 협력시스템 참고 화면의 중성 다크그레이와 청록 포인트로 되돌린다. 각 업무군 메뉴는 사용자가 필요할 때 개별적으로 접고 펼칠 수 있게 한다.

## 범위

- 248px 고정형 단일 사이드바와 44px 상단 바 구조는 유지한다.
- 사이드바의 녹색 기운이 도는 차콜 토큰을 중성 다크그레이 계열로 바꾼다.
- 활성 메뉴는 현대백화점 계열 청록 배경과 흰색 텍스트를 유지한다.
- 각 업무군 제목은 아코디언을 여닫는 버튼이 된다.
- 메뉴는 초기 상태에서 모두 펼쳐 둔다.
- 각 그룹은 다른 그룹과 독립적으로 접고 펼칠 수 있다.
- 접힌 그룹은 제목, 아이콘, 펼침 상태 화살표만 남기고 하위 링크를 렌더링하지 않는다.

## 상호작용 및 접근성

- 그룹 제목 버튼은 현재 펼침 상태를 `aria-expanded`로 표현한다.
- 버튼은 해당 링크 목록을 `aria-controls`로 연결한다.
- 화살표 아이콘은 펼침/접힘 상태에 따라 회전한다.
- 활성 메뉴가 든 그룹도 사용자가 접을 수 있다. 이때 그룹 제목은 선택된 업무군임을 유지하고, URL·활성 메뉴 판정 규칙은 바꾸지 않는다.
- 링크의 정확한 라우트에만 `aria-current="page"`를 부여하는 기존 규칙을 유지한다.

## 시각 규칙

| 항목 | 값 |
| --- | --- |
| 사이드바 배경 | `#2f2f2f` |
| 브랜드 영역 | `#333333` |
| 구분선 | `rgb(255 255 255 / 10%)` |
| 일반 메뉴 텍스트 | `#d5d5d5` |
| 그룹 제목 | `#b8b8b8` |
| hover | `#3a3a3a` |
| 활성 메뉴 | `#168f78` |
| 활성 표시선 | `#27a890` |

## 테스트 기준

- 초기 렌더에서 8개 그룹과 14개 링크가 모두 보인다.
- 그룹 제목을 한 번 누르면 해당 하위 링크가 사라지고 `aria-expanded="false"`가 된다.
- 같은 제목을 다시 누르면 링크가 복원되고 `aria-expanded="true"`가 된다.
- 메뉴 접힘은 다른 그룹·현재 페이지·상단 바·로그인 셸에 영향을 주지 않는다.
- 기존 단위 테스트, 빌드, 시각 테스트를 모두 통과한다.
