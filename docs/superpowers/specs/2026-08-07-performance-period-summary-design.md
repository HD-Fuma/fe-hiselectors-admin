# 기간 성과 요약 카드 설계

## 목표

성과 대시보드와 크리에이터·콘텐츠·상품 분석 화면에 있는 `AI 성과 인사이트` 영역을 제거한다. 아직 제공하지 않는 AI 리포트 기능을 암시하지 않고, 현재 화면에서 이미 다루는 정량 성과를 이전 집계 기간과 비교해 보여준다.

## 범위

- 대상 화면: 성과 대시보드, 크리에이터 분석, 콘텐츠 분석, 상품 분석
- 기존 `PerformanceInsightCard`를 정량형 `PerformancePeriodSummary`로 교체
- 기존 우측 레일 너비와 전체 레이아웃은 유지
- 백엔드 API, AI 분석, 새로운 상세 페이지는 추가하지 않음

## 정보 구조

카드는 다음 정보를 위에서 아래로 표시한다.

1. `PERIOD SUMMARY` 보조 라벨과 `집계 완료` 상태
2. `기간 성과 요약` 제목과 화면별 핵심 지표명
3. 현재 기간 값과 이전 기간 대비 증감률
4. 최근 구간을 나타내는 얇은 미니 추이 그래프
5. 비교 기간과 최종 집계 시각

화면별 핵심 지표는 다음과 같다.

- 성과 대시보드: 구매 전환
- 크리에이터 분석: 크리에이터 구매 전환
- 콘텐츠 분석: 콘텐츠 구매 전환
- 상품 분석: 상품 구매 전환

## 시각 설계

- 기존 다크 카드의 위치와 시각적 무게는 유지하되 AI를 연상시키는 오브, 번개 아이콘, 그라데이션 버튼은 제거한다.
- 배경은 짙은 녹색 계열, 텍스트는 흰색과 저채도 민트로 구성한다.
- 증감률은 상승 시 민트, 하락 시 연한 주황으로 표시한다.
- 미니 그래프는 장식이 아니라 기간 흐름을 전달하는 1.5px 선으로 그린다.
- 클릭 CTA를 제거해 제공되지 않는 상세 리포트로 이동할 것처럼 보이지 않게 한다.

## 컴포넌트 경계

`PerformancePeriodSummary`는 다음 값만 props로 받는 표현 컴포넌트다.

- `label`: 핵심 지표명
- `value: string | null`: 현재 기간의 표시 값. `null`은 집계 데이터가 없음을 뜻한다.
- `change: number | null`: 포맷되지 않은 증감률 숫자. `null`은 이전 값이 0이고 현재 값이 양수여서 비율 비교가 불가능하거나 집계 데이터가 없는 상태를 뜻한다.
- `changeLabel?: "신규"`: 이전 값이 0이고 현재 값이 양수인 비교 불가 상태에만 사용한다.
- `period`: 비교 기간 문구
- `updatedAt`: 최종 집계 시각
- `status: "complete" | "empty"`: 집계 완료 여부
- `points: readonly { label: string; value: number }[]`: 현재 기간의 날짜 오름차순 일별 값

페이지는 신규 `PERFORMANCE_PERIOD_SUMMARIES` fixture에서 범위별 현재 기간 합계, 이전 기간 합계, 현재 기간 일별 값을 읽어 위 값을 만들어 전달한다. 기존 크리에이터·콘텐츠·상품 entity aggregate를 시간 데이터로 오해해 재사용하지 않는다. 현재 선택된 2026-08-01~2026-08-03과 길이가 같은 직전 기간인 2026-07-29~2026-07-31을 비교한다. 증감률은 `(현재 합계 - 이전 합계) / 이전 합계 × 100`으로 계산하고 화면에는 소수점 첫째 자리까지 반올림한다. 이전 값과 현재 값이 모두 0이면 `0.0%`, 이전 값이 0이고 현재 값이 양수면 `신규`로 표시한다. 컴포넌트는 AI 판단이나 문장 생성 없이 fixture 숫자와 상태만 렌더링한다.

미니 그래프는 `points`의 원래 값을 컴포넌트 내부에서 카드 좌표에 맞게 정규화한다. SVG는 `role="img"`와 `aria-label`을 가지며 `8월 1일 320건, 8월 2일 470건`처럼 날짜와 원값을 텍스트 대체 정보로 제공한다. 빈 배열이면 그래프를 렌더링하지 않고, 한 개 값은 점 하나, 모든 값이 같으면 중앙 수평선으로 표시한다. 음수·무한대·NaN 값은 fixture 오류로 간주해 0으로 보정한다.

## 예외 처리

- 데이터가 없으면 값과 증감률 대신 `집계 데이터 없음`을 표시하고 그래프를 숨긴다.
- 0%는 중립 색상으로 표시한다.
- 음수 변화율은 하락 색상과 아래 방향 표시를 사용한다.
- `points`가 카드 너비를 넘지 않도록 SVG는 유동 너비 viewBox를 사용한다.
- 보조 정보는 스크린 리더가 지표명, 현재 값, 증감률, 기간 순서로 읽을 수 있게 구성한다.

## 검증

- 네 성과 화면에서 `AI REPORT`, `AI 성과 인사이트`, `인사이트 확인` 문구가 존재하지 않는지 테스트한다.
- 화면별 보이는 제목 `기간 성과 요약`, 보조 라벨 `PERIOD SUMMARY`, 핵심 지표가 렌더링되는지 테스트한다.
- 양수·음수·0·데이터 없음 상태의 표현을 컴포넌트 테스트로 검증한다.
- Pages 빌드와 1440px 실제 렌더링을 확인한다.
- 기존 960px 및 768px 레일 축소 구간에서 카드가 넘치거나 정보 순서가 깨지지 않는지 확인한다.
