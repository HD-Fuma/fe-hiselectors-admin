# 성과 대시보드 재설계

## 목표

기존 기능 명세의 필터, KPI, 캠페인·셀렉터스·크리에이터·콘텐츠 표를 유지하면서 성과의 추이와 비교가 먼저 읽히는 관리자 대시보드로 바꾼다. 화면은 정적인 UI 시안이며 새로운 동작이나 API는 추가하지 않는다.

## 디자인 방향

- 현대백화점 관리자 시스템의 짙은 회색과 청록색을 유지한다.
- 표보다 시각 요약을 먼저 배치한다.
- 둥근 카드와 넉넉한 여백을 사용하지만 소비자용 서비스처럼 장식적으로 만들지 않는다.
- 청록색은 핵심 성과, 짙은 회색은 기준값, 주황색은 전환 성과에 사용한다.
- 그래프는 별도 라이브러리 없이 접근 가능한 SVG와 HTML 막대로 구현한다.
- 일반 텍스트는 4.5:1, 그래프 선·막대·포커스 표시는 3:1 이상의 WCAG AA 대비를 확보한다.

## 화면 구조

### 관리자 성과 대시보드

1. 조회 조건
2. KPI 카드 4개: 총 클릭, 구매 전환, 전환율, 집계 셀렉터스
3. 선택 기간 성과 추이: 클릭과 구매 전환의 이중 선 그래프. 클릭은 왼쪽 축, 전환은 오른쪽 축을 사용하며 두 축 모두 0에서 시작한다.
4. 캠페인 전환 성과: 전환율 기반 가로 막대 그래프
5. 셀렉터스 성과 순위: 전환 수 기반 순위 카드
6. 기존 캠페인별·셀렉터스별 상세 표

### 크리에이터 영향력 분석

1. 조회 조건
2. 조회·좋아요·댓글·구매 전환 KPI
3. 크리에이터 영향력 비교: 조회 수 막대와 구매 전환 수 점을 독립적으로 정규화해 함께 표시하고, 실제 수치를 항상 텍스트로 병기한다.
4. 기존 상세 표

### 콘텐츠 영향력 분석

1. 조회 조건
2. 콘텐츠 수·조회·반응·구매 전환 KPI
3. 콘텐츠 성과 순위: 콘텐츠별 조회 수 막대와 전환율 정보
4. 기존 상세 표

## 컴포넌트 경계

- `PerformanceKpiGrid`: 수치와 보조 문구를 표시한다. 비교 기간 데이터가 없으므로 변화율이나 상승·하락 표시는 넣지 않는다.
- `PerformanceTrendChart`: 일별 클릭·전환 추이를 SVG로 표시한다.
- `PerformanceBarChart`: 캠페인, 크리에이터, 콘텐츠의 비교 막대를 표시한다.
- `PerformanceRanking`: 셀렉터스 성과 순위를 표시한다.
- 기존 `PerformanceFilters`, `PerformanceResultTable`은 유지한다.

## 데이터

- 기존 fixture의 합계와 항목별 성과를 그대로 사용한다.
- 일별 추이는 기본 조회 기간인 2026-08-01부터 2026-08-03까지의 합계가 전체 합계와 일치하는 fixture를 추가한다. 이후 실제 필터 동작이 개발되면 선택 기간의 일 단위 데이터만 표시하고, 14일을 넘으면 일별 값을 주 단위로 집계한다.
- 모든 필터는 KPI, 그래프, 순위, 표에 동일한 필터 결과를 적용한다. 이번 정적 UI 범위에서는 기본 조회 조건 데이터만 표시한다.
- 그래프 값은 동일한 fixture에서 계산해 표와 불일치하지 않게 한다.

## 정렬과 표시 규칙

- 캠페인 막대는 전환율 내림차순, 셀렉터스 순위는 구매 전환 수 내림차순으로 정렬한다.
- 크리에이터와 콘텐츠 그래프는 구매 전환 수 내림차순으로 정렬한다.
- 동률이면 ID 오름차순으로 정렬한다.
- 각 그래프는 최대 5개 항목을 표시하며 전체 데이터는 아래 표에서 확인한다.
- 긴 이름은 한 줄 말줄임으로 표시하되 `title`과 접근 가능한 목록에는 전체 이름을 제공한다.
- 클릭 수가 0인 전환율은 `0.00%`로 표시한다.
- 막대와 선은 항상 0을 기준으로 하고, 최대값이 0이면 빈 그래프 대신 “표시할 성과 데이터가 없습니다” 상태를 보여준다.

## 빈 상태

- 필터 결과가 없으면 KPI는 `-`, 그래프와 순위는 공통 빈 상태, 표는 기존 빈 행 메시지를 표시한다.
- 결과는 있지만 모든 값이 0이면 KPI는 `0`, 그래프는 0 데이터 안내를 표시하고 표는 유지한다.

## 접근성

- 모든 그래프는 `figure`, `figcaption`, `aria-labelledby`로 명확한 이름을 가진다.
- SVG는 보조 기술에서 숨기고, 바로 인접한 시각적으로 숨겨진 목록에 모든 날짜·항목·수치를 제공한다.
- 색상만으로 지표를 구분하지 않고 범례, 선 모양, 수치 레이블을 함께 표시한다.
- 가로 막대에는 실제 값을 텍스트로 노출한다.

## 검증

- 기존 기능 명세 테스트가 요구하는 제목, 필터, 표, 수치는 유지한다.
- Vite 프로덕션 빌드로 타입 변환과 번들 생성을 확인한다.
- 로컬 화면에서 1440px, 1024px, 768px 기준 레이아웃과 그래프 잘림 여부를 확인한다.
- 좁은 화면에서 KPI와 그래프는 단일 열로 재배치하고 표는 가로 스크롤을 유지한다.
- 긴 레이블, 키보드 포커스, 접근 가능한 그래프 데이터 목록을 확인한다.
