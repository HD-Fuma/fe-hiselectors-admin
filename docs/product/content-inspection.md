# 콘텐츠 검수 요구사항

## 처리 단계

1. 이미지·영상과 제목, 본문, 해시태그, 멘션, URL 수집
2. OCR과 ASR/STT로 텍스트·등장 시간·화면 위치 추출
3. 광고 표시, 필수/금지 문구, 해시태그, 멘션, URL 규칙 검사
4. 제출 정보 일치, 과장 표현, 브랜드 적합성, 수정 근거 AI 분석
5. 관리자가 원문과 AI 분석 근거를 확인하고 최종 승인 또는 반려

## 화면 최소 정보

- 작성자 프로필·이름·계정·플랫폼
- 콘텐츠 제목과 형식
- 최초 등록일과 마지막 수정
- 버전 선택
- 콘텐츠 원문
- AI 분석(콘텐츠 요약, 위반 내역, 수정 버전의 변경점)
- 같은 번호로 연결된 위반 항목과 위반/위반 허용 판정, 승인·반려 action

## UI 원칙

- 위반 항목을 근거 영상 시간 또는 화면 위치와 연결합니다.
- 자동 추출, 규칙 검사, AI 판단을 구분합니다.
- 승인·반려 전에 선택한 버전의 원문과 AI 분석 근거를 확인할 수 있어야 합니다.
- 원문 위치, 위반 내역, 관리자 판정은 같은 번호로 연결합니다.
- 관리자가 모든 위반 항목을 위반 또는 위반 허용으로 고른 뒤에만 승인·반려할 수 있습니다.
- AI 판단만으로 최종 상태를 확정하지 않습니다.
- 위반 내역에는 API의 violationItem을 위반 항목 카드로 표시하고, 10종 위반 유형 중 응답에 없는 항목과 정상 판정 제목·근거는 하나의 펼쳐진 `가이드 준수 항목` 목록에 함께 표시합니다. 정상 판정 설명은 표시하지 않습니다.
- 위반 항목 카드는 번호가 붙은 위반 제목, 검수 기준, 설명 순서로 표시하며 위치와 검출 문구는 원문의 동일 번호 마커에서 확인합니다.
- 목록 처리 구분은 `전체`, `신규 등록`, `수정 감지`, `위반 확정`, `승인 완료`입니다. 승인과 반려를 한 탭으로 묶지 않습니다.
- `위반 확정`에서는 위반 항목 토글을 켠 채 잠그고, `승인 완료`에서는 끈 채 잠급니다.
- 최종 검수 action은 최신 콘텐츠 버전에서만 표시합니다. 검수 전에는 `반려`·`승인`을 모두 표시하고, 판정 완료 후에는 실제 판정과 같은 버튼 하나만 전체 너비로 표시합니다.
- 최종 검수 요약은 `검수 정책`, `검수 상태`, `항목 판정` 3열이며 검수 정책에는 정책 번호만 표시합니다.
- 최종 검수 상태는 선택 버전 API의 `inspectionDecision`을 기준으로 `승인`, `반려`, `검수 전`을 표시하고, 제출 직후에는 응답을 기다리지 않고 선택 결과를 반영합니다.
- 상세 상단의 `검수 목록`은 브라우저 뒤로가기가 아니라 콘텐츠 검수 목록으로 이동합니다. `이전 콘텐츠`와 `다음 콘텐츠`는 현재 검수 대기열 안에서 이동합니다.
- 목록의 `검수 시작` 버튼으로 대기열 세션에 진입한 경우에만 도움말 아이콘을 표시합니다. 첫 콘텐츠에서 아이콘에 `도움말을 확인할 수 있습니다.` 툴팁을 잠시 띄우고, 호버 시에도 같은 툴팁이 나타나며, 클릭하면 화면을 어둡게 한 뒤 영역별 가이드 투어를 시작합니다. 투어는 클릭으로 다음, 아래로 스크롤하면 다음·위로 스크롤하면 이전으로 이동하고, 1단계에서는 마우스 휠 애니메이션을 보여 줍니다. 카드·행 클릭으로 단일 검수에 들어온 경우에는 도움말을 숨깁니다. 프로필을 누르면 라우트를 바꾸지 않고 셀렉터스 상세 패널만 엽니다.
- 과거 버전과 최신 버전은 같은 플랫폼 카드 렌더러와 포맷별 동일 크기를 사용합니다. 인스타그램 피드는 정사각형 미디어·프로필 헤더·action·본문, 인스타그램 릴스는 같은 셸 안의 9:16 미디어, 유튜브 롱폼은 16:9 미디어·채널·action·설명, 유튜브 쇼츠는 9:16 전체 미디어·오른쪽 action 레일·하단 채널과 본문으로 구성합니다. 쇼츠 카드는 롱폼 카드와 별도 포맷 변형을 사용합니다.
- 플랫폼 카드는 왼쪽 검수 영역(오른쪽 레일 제외) 안에서 상하·좌우 중앙에 배치합니다. 긴 본문은 카드 높이를 늘리지 않고 최대 6줄과 `더보기`를 표시하며, 본문 텍스트 영역이나 `더보기`를 누르면 텍스트 데이터 팝업이 열립니다. 펼친 본문만 카드 내부에서 스크롤합니다.
- 오른쪽 레일은 위에 셀렉터스 프로필, 아래에 검수 리포트를 둡니다. 리포트 메타는 `최초 수집 일시`·`수집 일시`·`유형`을 줄마다 라벨+값 한 줄로 표시합니다. 선택한 콘텐츠 카드 아래에는 선택 글로우를 표시합니다. 과거 버전 카드를 선택하면 해당 버전의 요약·메타·위반 내역을 읽기 전용으로 표시하고, 리포트 제목 옆에 `과거 콘텐츠` 배지를 붙이며 항목 판정 버튼과 최종 action을 숨깁니다. 최신 버전 카드를 선택하면 최신 리포트, 항목 판정 버튼, 최종 승인·반려 action을 표시합니다.
- 항목 판정 action은 `위반`과 `위반 허용`을 사용합니다. 판정 카드의 왼쪽 띠와 별도 상태 칩은 표시하지 않습니다. 판정 상태는 카드 전체 테두리·배경과 판정 버튼의 선택 상태로 표시하고, 키보드 포커스와 현재 연결된 위반 항목은 독립 외곽 링으로 구분합니다.

## 위치 주석 계약

- API evidence의 `contentMediaId`로 선택 버전의 `media`와 위치를 연결합니다.
- image bbox는 원본 이미지 픽셀 좌표이며 로드된 원본 크기로 화면 비율을 계산합니다.
- video의 초 단위 `startTime/endTime`은 시간 라벨이 있는 미디어 마커로 표시합니다.
- text 위반은 해당 미디어 `body.text` 기준 UTF-16 `[startIndex, endIndex)`를 사용합니다.
- 좌표가 없는 media-level location은 해당 미디어 또는 콘텐츠 카드 헤더 경고 배지로 표시합니다.
- locations가 비어 있으면 콘텐츠 전체 위반으로 근거 패널에만 표시합니다.
- 검수 출처는 evidence의 `RULE`/`AI` 값을 배지로 구분합니다.
- URL 위반은 `targetIndex`로 해당 link row와 연결합니다.
- `state: "active"`인 annotation만 원본 표시와 안내 rail을 만듭니다. 다만 과거 버전을 선택하면 현재 해결·기각 상태와 별개로 당시 evidence 위치를 표시합니다.
- 번호가 같은 원본 mark와 안내문을 연결하고, 색상 외에도 번호·아이콘·텍스트로 구분합니다.
- 위반 안내 버블은 카드 오른쪽을 우선 사용하되 검수 리포트와 겹치지 않으며, 우측 공간이 부족하면 카드 왼쪽에 배치합니다.
- quote나 index가 원본과 맞지 않으면 잘못된 위치를 추정하지 않습니다. 원본 강조는 생략하고 안내문은 해당 section에 유지합니다.
- annotation은 `detectedIssues`나 분석 문장에서 UI가 추론하지 않고 typed fixture/API data로 받습니다.

## 관리자 확정 계약

- 모든 후보를 판정한 뒤 `PATCH /api/admin/contents/{contentId}/versions/{contentVersionId}/inspection`을 한 번 호출합니다.
- 승인은 `APPROVED`, 반려는 `REJECTED`로 보내며 후보에는 실제 `violationItemId`와 목표 상태만 담습니다.
- 위반 판정은 `VIOLATION_CONFIRMED`, 위반 허용 판정은 `DISMISSED`를 사용합니다.
- 화면 번호, 한국어 판정명, 중간 `PENDING` 상태는 요청에 포함하지 않습니다.
- 성공 후 선택 버전 상세를 다시 조회해 서버가 확정한 상태를 화면에 반영합니다.
